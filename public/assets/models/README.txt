Place your mechanical part model here as:
  mechanical-part.glb

Export from SolidWorks: File > Save As > glTF (.glb), or convert an
STEP/STL export via an online/CLI converter. Keep it under ~5MB and
centered near the origin for best results.

Until this file exists, src/three/hero-scene.js automatically falls
back to a procedural wireframe gear-and-shaft assembly — the site
works correctly either way, no code changes required.
